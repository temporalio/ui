## Getting started

Import each component from its own entry point. Inside this repository, use
`$lib/io/{name}` and in other apps, use `@temporalio/ui/io/{name}`.

```ts
import { Button } from '$lib/io/button';
import { Badge } from '@temporalio/ui/io/badge';
```

Configure the theme preset from `@temporalio/ui/theme/preset`, and prefer
semantic classes such as `text-primary`, `bg-surface-primary`, and
`border-primary` so your UI follows the selected theme.

Each component page has a live Playground, examples, Do / Don't guidance, and an
API reference.

## For agents

These docs are also published as plain text for AI tools, following the
[llms.txt](https://llmstxt.org) convention. Every file is generated from the
same Markdown as the guide and component pages, so it stays current with them.

{/* MDX here has no GFM tables; the Markdown block renders them. */}

<Markdown>{`
| File | Contents |
| ---- | -------- |
| <a href="${docsUrl('llms.txt')}" target="_blank"><code>/llms.txt</code></a> | An index of the docs, with a link to every guide and component's Markdown page. |
| <a href="${docsUrl('llms-full.txt')}" target="_blank"><code>/llms-full.txt</code></a> | Every guide and component page in one file. |
| \`/io/<slug>.md\` | One page. A guide's page is the guide itself. A component's page has its description, usage guidance, Do / Don't rules, and the API reference, and is also under Copy page on the component. |
`}</Markdown>

Start an assistant from the index, which links to everything else. In Cursor,
add the `/llms.txt` link under Docs and reference it with `@Docs`. In Claude
Code and other assistants, include it in a prompt or your project's
`AGENTS.md`. For large context windows, attach `/llms-full.txt` instead.
