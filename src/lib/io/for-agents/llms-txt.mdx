# LLMs.txt

Plain-text versions of the io docs for AI tools, following the
[llms.txt](https://llmstxt.org) convention. Point an assistant at them so it
uses io components the way these docs describe.

## Files

Every file is generated from the same Markdown as the component pages, so it
stays current with them.

{/* MDX here has no GFM tables; the Markdown block renders them. */}

<Markdown>{`
| File | Contents |
| ---- | -------- |
| <a href="${origin}/llms.txt" target="_blank"><code>/llms.txt</code></a> | An index of the docs and every component, with a link to each component's Markdown page. |
| <a href="${origin}/llms-full.txt" target="_blank"><code>/llms-full.txt</code></a> | Every component's Markdown page in one file. |
| \`/io/<slug>.md\` | A component's page: description, usage guidance, Do / Don't rules, and the API reference. Also under Copy page on each component. |
`}</Markdown>

## Usage

Any tool that reads llms.txt can use these files. Start from the index, which
links to everything else.

- **Cursor:** add the `/llms.txt` link under Docs, then reference it with
  `@Docs`.
- **Claude Code and other assistants:** include the link in a prompt or in your
  project's `AGENTS.md`.
- **Large context windows:** attach `/llms-full.txt` to give the whole system at
  once.
